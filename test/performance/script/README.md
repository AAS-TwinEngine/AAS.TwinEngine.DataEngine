# K6 Performance Test Scripts

This directory contains K6 performance test scripts used to validate and benchmark DataEngine endpoints.

## Prerequisites

Before running the tests, ensure that:

- K6 is installed locally: https://k6.io/
- A DataEngine instance is running and accessible.
- A `.env` configuration file exists in this directory.

## Configuration

Create a `.env` file in this directory and add the following configuration:

```env
BASE_URL=http://localhost:8080

VUS=1
MAX_DURATION=10m
LOAD_ALL_SHELL_DESCRIPTORS_MAX_DURATION=60m
GRACEFUL_STOP=30s
SETUP_TIMEOUT=10m

LOG_REQUESTS=false

DISCOVER_PAGE_LIMIT=1000
MAX_DISCOVERED_IDS=0

ENDPOINT_GET_SHELLS=true
ENDPOINT_GET_SHELLS_REQUESTS=10

ENDPOINT_GET_SHELL_BY_ID=true
ENDPOINT_GET_SHELL_BY_ID_REQUESTS=10

ENDPOINT_GET_ASSET_INFORMATION=true
ENDPOINT_GET_ASSET_INFORMATION_REQUESTS=10

ENDPOINT_GET_SUBMODEL_REFERENCES=true
ENDPOINT_GET_SUBMODEL_REFERENCES_REQUESTS=10

ENDPOINT_GET_SHELL_DESCRIPTORS=true
ENDPOINT_GET_SHELL_DESCRIPTORS_REQUESTS=10

ENDPOINT_GET_SHELL_DESCRIPTOR_BY_ID=true
ENDPOINT_GET_SHELL_DESCRIPTOR_BY_ID_REQUESTS=10

ENDPOINT_GET_SUBMODEL_DESCRIPTORS=true
ENDPOINT_GET_SUBMODEL_DESCRIPTORS_REQUESTS=10

ENDPOINT_GET_SUBMODEL_DESCRIPTOR_BY_ID=true
ENDPOINT_GET_SUBMODEL_DESCRIPTOR_BY_ID_REQUESTS=10

ENDPOINT_GET_SUBMODELS=false
ENDPOINT_GET_SUBMODELS_REQUESTS=10

ENDPOINT_GET_SUBMODEL_BY_ID=true
ENDPOINT_GET_SUBMODEL_BY_ID_REQUESTS=10

ENDPOINT_LOAD_ALL_SHELL_DESCRIPTORS=true
ENDPOINT_LOAD_ALL_SHELL_DESCRIPTORS_REQUESTS=1
LIMIT_FOR_ALL_SHELL_DESCRIPTORS=1000

REPORT_OUTPUT_PATH=results

EXPORT_CSV=true
EXPORT_JSON=true
```

## File Overview

| File | Description |
|--------|-------------|
| `main.js` | Main K6 test entry point. |
| `helpers/config.js` | Loads and validates configuration from the `.env` file. |
| `helpers/setup.js` | Discovers Shell and Submodel IDs required for testing. |
| `helpers/scenarios.js` | Defines endpoint test scenarios and custom metric names. |
| `helpers/requests.js` | Executes requests and collects custom metrics. |
| `.env` | Test configuration file. |
| `results/summary.json` | JSON summary report. |
| `results/results.csv` | CSV report containing test results. |
| `results/k6-summary-report.html` | HTML dashboard report generated by K6. |

## Running the Tests

Run the following command from this directory:

```powershell
k6 run main.js
```

## Generating an HTML Summary Report

### PowerShell

```powershell
$env:K6_WEB_DASHBOARD="true"
$env:K6_WEB_DASHBOARD_EXPORT="results/k6-summary-report.html"

k6 run main.js
```

### Command Prompt (CMD)

```cmd
set K6_WEB_DASHBOARD=true
set K6_WEB_DASHBOARD_EXPORT=results/k6-summary-report.html

k6 run main.js
```

## Test Outputs

All generated reports are stored in the `results` directory:

- **CSV Report:** `results/results.csv`
- **JSON Summary:** `results/summary.json`
- **HTML Dashboard Report:** `results/k6-summary-report.html` (generated only when dashboard export is enabled)

## Notes

- Individual endpoints can be enabled or disabled using the corresponding `ENDPOINT_*` configuration flags.
- The numbe* of requests executed per endpoint*can be configured through the matching `*_REQUESTS` settings.
- The setup phase automatically discovers available Shell and Submodel IDs before executing endpoint-specific tests.
- Setting `MAX_DISCOVERED_IDS=0` removes the discovery limit and uses all discovered IDs.
- Request logging can be enabled by setting `LOG_REQUESTS=true`.
- `LIMIT_FOR_ALL_SHELL_DESCRIPTORS` controls the `limit` query parameter for the LoadAllShellDescriptors scenario. Use a positive integer.
